# Aerospace Opportunity Board

Personal daily dashboard for a **Nigerian Mechanical Engineering undergraduate (300 level)** focused on **aerospace / space** pathways.

Live site (after GitHub Pages is enabled):

**https://jsky11.github.io/aerospace-opportunities/**

## What this site shows

- Urgent / open / forecast / excluded filters
- Deadline strip (Africa/Lagos)
- Opportunity cards with funding, eligibility, aerospace relevance, and official apply links
- 30-day action checklist

## Enable GitHub Pages (one-time)

1. Open the repo: https://github.com/Jsky11/aerospace-opportunities  
2. **Settings → Pages**  
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**  
4. Branch: **main** / folder: **/ (root)** → Save  

GitHub will publish the site in about a minute.

## Update workflow

Content lives in:

- `data.js` — opportunities, deadlines, next steps, last-updated stamp  
- `index.html` / `styles.css` / `app.js` — layout and interaction  

After each scout run, update `data.js` (and the date stamp) and push to `main`.
